Shared Agent Memory — Hindsight on Azure

One memory service for the cross-site team · Azure Container Apps + PostgreSQL Flexible Server + Azure AI Foundry · Draft v2 · September 8, 2026

Data Layer

  • • PostgreSQL Flexible Server PG 17 — the single stateful component
  • • vector 0.8.2 (HNSW) active; iterative index scans supported (≥ 0.8.0)
  • • pg_diskann 0.6.5 allow-listed from day 1 — scale switch is config + re-index
  • • Private access, sslmode=require, PITR 14 days
  • • Start B2ms / 32 GiB autogrow — grow to D2ds_v5 when latency pinches

Models — AI Foundry

  • • gpt-5-mini — extraction, reflect, consolidation (Data Zone EU)
  • • text-embedding-3-small — 1536 dims, dimension-locked at first retain
  • • Cohere-rerank-v4.0-fast — invoke URL used verbatim; first deployment rrf, then failover member rrf
  • • Base URL gotcha: https://<res>.openai.azure.com/openai/v1
  • • If key auth is disabled by policy: route via APIM AI Gateway (managed identity)

Access & Security

  • • Phase 1: shared bearer key (ApiKeyTenantExtension), distributed via 1Password
  • • Phase 2: APIM — per-user subscriptions, Entra ID JWT, per-caller passthrough header
  • • Key Vault + user-assigned managed identity — no secrets in app config
  • • Control Plane behind Entra ID (ACA built-in auth) + access key
  • • Shared memory language forced to English (LLM_OUTPUT_LANGUAGE)
