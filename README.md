# AgenticIDE

Working environment for IDE-related topics in the agentic era — for local (localhost) setups as well as for our cross-site team.

Example topics: agent harnesses, agent memory solutions, IDE/editor configuration, agentic workflows.

## Topics

| Folder | Topic |
|--------|-------|
| [`agent-memory/`](agent-memory/) | Shared agent memory — Hindsight on Azure (deployment plan + architecture) |
| [`secrets-management/`](secrets-management/) | Secrets for agentic tooling — 1Password-backed environment variables (plan, zsh loader, templates, installer) |

## Conventions

- One top-level folder per topic, self-contained with its own README and tooling.
- All content is written in English (en-US).
- Visual artifacts (especially HTML) follow the ANDRITZ corporate design.
- State OS assumptions explicitly — the team works across macOS and Windows + WSL2.
